# Site Learn more page tops

The top of each Learn more page has the breadcrumb, the label, the headline with its shine line and the lead. Under them sit Book a demo, Get started and the built-for pills, and the hero card sits beside them. Recruitment and Onboarding also have the turning rings behind the card. Each page top is shown at desktop width and at 390px. The cards loop on their own from a preview-only script, not from a component.

## Screens

- **Learn more top: Recruitment**. The hiring pipeline for one role. The counts move as candidates change stage. Uses Site hero, Site form page, Site rings, Site hero card, Site button.
- **Learn more top: Onboarding**. John Doe's six onboarding steps, with the meter following them. Uses Site hero, Site form page, Site rings, Site hero card, Lozenge.
- **Learn more top: Compliance**. The register counts the days from 3 Nov. The forklift licence expires, then the renewal is accepted. Uses Site hero card, Site ledger (tiles).
- **Learn more top: Leave**. John Doe's annual leave request is approved, and the balance counts down from 15 to 11 days. Uses Site hero card, Site leave balances.
- **Learn more top: Security**. The audit log fills one entry at a time. Uses Site hero card, Site audit log, Site who did it.
- **Learn more top: Platform**. Naleko switches on three modules one by one. Uses Site hero card, Site modules, Toggle.
