Approvals

A person approves every action.

Batsi suggests, drafts and reminds. Nothing is sent, accepted or changed until HR approves it. Writes that arrive through the API or the MCP server wait in the same approval queue.

  • Batsi drafts, a person approvesBatsi
  • Nothing sent or saved before approval
  • API and MCP writes use the same queue
  • Approver recorded with a name and a time
  • Rejected actions logged with the reason

Audit trail

Every step recorded, and exported in one step.

Every upload, check, approval and view goes into the audit log. Each entry shows who did it, when, and whether it was a person or Batsi.

  • Name, time and what happened on every entry
  • Person or Batsi shown on each entry
  • Views of personal data logged
  • Export to CSV for an audit
  • Entries kept with the name of who made them

Hidden data

Personal data is hidden until someone needs it.

ID number, bank account and salary are hidden by default. Each Show is logged with the name of the person who asked, and the value hides again.

  • ID, bank and salary details hidden by default
  • Each Show logged with a name and a time
  • Values hide again on leaving the page or after 2 minutes
  • Access limited by role

POPIA consent

Consent is recorded before any document is collected.

An employee or candidate agrees to the privacy notice first. Only then can a document be uploaded. The consent is kept on the record with its date and time.

  • Privacy notice shown before the first upload
  • Upload unlocked once consent is given
  • Consent kept with its date and time
  • Document reading described in the privacy notice
