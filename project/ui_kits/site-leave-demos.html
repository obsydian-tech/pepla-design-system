Leave types

Leave types set to the BCEA.

Annual, sick, family responsibility and maternity leave start with the rules of the Basic Conditions of Employment Act. Companies add their own leave types in settings.

  • Annual, sick, family responsibility and maternity leave
  • Sick leave tracked over a 36-month cycle
  • Company leave types added in settings
  • Entitlement set per employee type
  • Every change to a leave type logged

Requests

Employees request leave from a phone.

An employee picks the leave type and the dates. Naleko People counts the working days, leaves out weekends and public holidays, and sends the request to the line manager.

  • Request made from a phone in a few taps
  • Working days counted automatically
  • Weekends and public holidays left out
  • Balance shown before the request is sent
  • Request goes to the line manager

Approvals

The line manager approves. Batsi follows up.

Each request goes to the line manager with the dates, the working days and who else is off. A request left waiting gets a reminder from Batsi. Approving or declining takes one tap.

  • Request sent to the line manager
  • Dates, working days and team overlap shown
  • Reminder sent when a request waitsBatsi
  • Decline recorded with a reason
  • Every decision logged with who made it

Balances and calendar

Balances update on approval. The calendar shows who is off.

When a request is approved, the days come off the balance on the employee record and appear on the team calendar. Sick leave is counted over the 36-month cycle.

  • Balance updated the moment a request is approved
  • Team calendar with public holidays marked
  • Sick leave tracked over 36 months
  • Balances kept on the employee record
