# Site Learn more page endings

After the five demo sections, each Learn more page ends the same way: the Ask Batsi band with three of the page's own questions, the trust strip, "Works together with" and the questions. The closing band and footer follow (see Site landing page). Each page ending is shown at desktop width and at 390px. The Ask Batsi chat plays the page's questions from a preview-only script, not from a component.

## Screens

- **Learn more ending: Recruitment**. Ask Batsi about any open role. Uses Site Ask Batsi, Site trust strip, Site related modules, Site module cards, Site questions.
- **Learn more ending: Onboarding**. Ask Batsi about any new employee. Same parts.
- **Learn more ending: Compliance**. Ask Batsi about any certificate. Same parts.
- **Learn more ending: Leave**. Ask Batsi about leave. Same parts.
- **Learn more ending: Security**. Ask Batsi what was done, and by whom. The strip has no link, because this is the Security page. Same parts.
- **Learn more ending: Platform**. Ask Batsi across every module. Same parts.

## Where the redraw changes the approved site

See `DEVIATIONS.md` for the full table. In short:

- **Words follow the rules.** "masked" and "Masked" read "hidden" and "Hidden". Straight apostrophes are typographic.
- **Icons are design system icons.** The related cards use the landing module card icons, and their icon fills on hover like the landing cards.
- **A neutral chat status.** Rows the source marked grey ("Open", "Not shown") use the plain status.
