Integrations

Batsi works inside existing systems.

Naleko People connects to HR, payroll and finance systems through a REST API, an MCP server and events. Keys are issued per company. Every write from outside goes into the same approval queue as Batsi’s own suggestions.

check-new-hire.ts
// Ask Batsi to check a new hire from any system
const check = await naleko.checks.run({
  employee: 'John Doe',
  documents: ['id', 'matric', 'bank_letter'],
  approver: 'Jane Smith'
});
// check.status → "waiting_for_approval"
// check.flags  → ["uif_reference_missing"]

  • REST API

    Per-company keys. Read records, start checks and send documents from any HR, payroll or ERP system.

  • MCP server

    AI assistants used inside the company ask Batsi for answers and drafts. Each tool allowed or blocked by the company.

  • Events and webhooks

    Onboarded, leave approved, certificate expiring. Each change posted to the systems that need it.

  • Approval queue on every write

    Writes from the API or an AI assistant wait for HR approval. Every call is in the audit log.
