# Site offboarding band

One line on how every exit is recorded, with its four parts as chips.

## Anatomy

1. **Band** (`pp-site-offboard`): violet wash, rounded; title, line and chips in one row from 1024px.
2. **Title** (`__title`), **line** (`__text`) and **chips** (`__chips`, a list of `__chip`).
